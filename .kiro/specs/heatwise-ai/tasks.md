### M1 findings carried forward
- Nova 2 Lite sent a number for a `list[str]` structured-output field and repeated it on every retry. Keep structured-output schemas small and flat, and derive lists deterministically. Cap retries with `Limits(structured_output_attempts=2)`.
- Nova added an unsupported claim ("clear skies") to its free-text summary. The prompt now forbids it, but free text still needs checking by the Safety agent (M2, Req 6.1).
- The default SDK tool executor runs tools concurrently, so traces are in completion order. The activity monitor (M3) should sort by start time or show calls as parallel.
